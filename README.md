# Add Two Numbers Using Python

This is a simple Python program that adds two numbers represented as lists.

The program:

* takes input from the user
* stores numbers in lists
* adds the numbers digit by digit
* handles carry values
* prints the final result

## Concepts Used

* Lists
* Loops
* Carry handling
* Modulo operator
* Floor division
* User input

## Example

Input:
l1 = [1,2,3]
l2 = [7,8,9]

Output:
[8,0,3,1]
